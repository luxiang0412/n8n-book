《从 n8n 到 Mini-n8n：从零构建 AI Agent Workflow 平台》大纲 ​

参照仓库：n8n-io/n8n @ 60ad29f242（packages/cli 版本 2.43.0） 读者目标：读完后，能从零写出一个前后端都能运行、支持 AI Agent 的 Workflow 自动化平台。 写作方式：每章先讲概念，再读 n8n 源码（路径:行号），再在 mini-n8n 里实现，最后给出真实运行结果。

贯穿全书的项目：mini-n8n ​

版本能力章节
v0.1数据模型、表达式与沙箱、栈式执行引擎、12 个核心节点、CLIPart II（4–8 章、Lab 1）
v0.2SQLite 持久化、REST API、生命周期钩子、SSE 推送、凭证加密、Webhook / Schedule 触发器Part III（9–12 章、Lab 2）
v0.3Vue 3 + Vue Flow 画布、参数面板（NDV）、表达式预览、运行与调试Part IV（13–15 章、Lab 3）
v0.4AI 连接类型、Chat Model（Mock / Ollama / OpenAI 兼容）、Tools Agent、EngineRequest、工具、记忆、Chat Trigger、流式Part V（16–21 章、Lab 4）
v0.5RAG（Embeddings、向量存储、检索工具）、Agent as Tool、人工审批（HITL）、结构化输出Part VI（22–23 章、Lab 5）
v1.0子工作流、等待与恢复、队列模式 + Worker、Code 节点 Task Runner、多用户与 API Key、Docker 部署Part VII（24–28 章、Lab 6）

默认技术栈：TypeScript monorepo（npm workspaces）、tsx、Vitest、Fastify、node:sqlite、Vue 3 + Pinia + Vue Flow。所有 AI 功能都能用离线的 Mock 模型运行，也用本地 Ollama（qwen2.5:0.5b）验证过。
